# Tijani Sylla - Portfolio Website

Modern, responsive portfolio website built with React, TypeScript, and Tailwind CSS.

🌐 **Live Site**: [https://tijanisylla.dev](https://tijanisylla.dev)

## 🚀 Features

- ⚡ **TypeScript** - Fully typed for better development experience
- 🎨 **Modern UI** - Beautiful, responsive design with dark/light theme
- 🎭 **Animations** - Smooth animations using Framer Motion
- 🎯 **SEO Optimized** - Complete meta tags, Open Graph, and structured data
- 📱 **PWA Ready** - Progressive Web App support
- 🎨 **Particles Background** - Interactive particle effects
- 📧 **Contact Form** - Integrated contact section
- 🔍 **Error Handling** - Error boundaries and 404 page
- ⚡ **Performance** - Optimized images and lazy loading

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS
- **UI Components**: Radix UI, shadcn/ui
- **Animations**: Framer Motion
- **Particles**: tsparticles
- **Build Tool**: CRACO (Create React App Configuration Override)

## 📦 Installation

```bash
# Install dependencies
cd frontend
npm install
# or
yarn install
```

## 🚀 Development

```bash
cd frontend
npm start
# or
yarn start
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 🏗️ Build

```bash
cd frontend
npm run build
# or
yarn build
```
